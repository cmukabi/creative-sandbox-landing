Privacy Policy — The Creative Sandbox

Effective Date: 13 November 2026 · Website: creativesandbox.co.uk

This Privacy Policy explains how The Creative Sandbox Chrome Extension ("the Extension") collects, handles, stores, and shares user data.

1. User Data Collection

The Extension does not require user accounts, logins, or personal registration. It processes only the data you explicitly provide or capture while using the tool:

  • Webpage Text & Page Metadata: When you highlight text on a webpage and select "Send to Creative Sandbox" (or invoke the extension), the Extension reads your selected passage along with the webpage's title, URL, and author metadata to populate the Source attribution box.
  • User-Authored Drafts & Prompts: Text, poetry, lyrics, and audio/video files you write or generate inside the side panel or popup studio.
  • User-Provided API Keys & Tokens: Optional Bring-Your-Own-Key (BYOK) credentials that you voluntarily enter into Settings (OpenAI API key, Anthropic API key, ElevenLabs API key, or Cloudflare Worker upload token).

2. How User Data Is Used & Handled

  • Core Writing & Formatting: Highlighted quotes, drafts, and timers are processed locally in your browser to run writing sprints, syllable/meter checks, and local text formatting.
  • On-Demand AI & Media Generation: When you explicitly click a generation or polish button (such as AI Poetry Polish, Devil's Advocate prompts, or Hymn/Song audio), your draft text is transmitted securely over HTTPS to your selected provider to return the requested output.
  • Optional Shareable Media Links: Only when you explicitly click "Get share link" in Card 5 does the Extension upload your rendered MP4 or audio file to generate a shareable link.
  • No Tracking or Advertising: We do not collect browsing history across websites, track user analytics, sell user data, or serve advertisements.

3. Data Storage & Security

  • Local Browser Storage: All active drafts, source attribution settings, preferences, and optional BYOK API keys are stored locally on your device using chrome.storage.local. Your API keys are never transmitted to our servers.
  • Cloudflare R2 Temporary Media Storage: If you choose to generate a shareable link for an MP4 lyric video or audio track in Card 5, that media file is stored on Cloudflare R2 object storage solely to serve playback via the generated share URL.

4. Third-Party Parties With Whom Data May Be Shared

User data is never sold or shared with data brokers. Data is transmitted to third-party processors only when you explicitly trigger an optional AI or cloud-sharing action:

  • OpenAI (://openai.com): Receives your prompt/draft text and your personal OpenAI API key when you select OpenAI for text polishing, constraint generation, or text-to-speech audio.
  • Anthropic (://anthropic.com): Receives your prompt/draft text and your personal Anthropic API key when you select Anthropic (Claude) for text polishing or constraint generation.
  • ElevenLabs (api.elevenlabs.io): Receives your lyrics/text and your personal ElevenLabs API key when you generate sung vocals or voice audio in Card 5.
  • Cloudflare Workers & Cloudflare R2 (*.workers.dev / ://cloudflarestorage.com): Receives your rendered MP4/audio file and upload token solely when you explicitly click "Get share link" to host a shareable media link.

5. Data Deletion & User Control

You retain full control over your data. You can clear saved API keys at any time using the "Clear Key" button in Settings, delete saved drafts inside the extension, or remove all locally stored data by uninstalling the Extension from Chrome.
